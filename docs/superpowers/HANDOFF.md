## Container notes

`etl/build/stats.db` (2024–2026, Kotlin-built, about 98 MB) and `etl/build/parity/{py,kt}.db` (2025) exist if this container survives; a fresh one has none, so rebuild them (commands in `CLAUDE.md`; the Python `build` alone lacks the `game` and projection tables that `:core:data` tests need, so build `stats.db` with the Kotlin command). `RealDatabaseContractTest > scoring a full season for every player is fast` can fail on timing here with or without any change; CI passes it. A fresh container has no Android SDK, no pytest and no `local.properties`: install platform 37.0 and build-tools 36.0.0 with `sdkmanager` (cmdline-tools from dl.google.com) into `/opt/android-sdk`, write `sdk.dir=/opt/android-sdk` to `local.properties` (git-ignored), export `ANDROID_HOME`, and `pip install pytest`. Gradle downloads hit Maven Central 429s for minutes at a time: loop `./gradlew ... --max-workers=2 -q` with a 40 s sleep until the log has no "429" or "Could not resolve". Robolectric tests fetch their own artifact and can fail on the same 429. Bash sometimes fails with a transient "classifier gave no verdict" error: retry once, or use Read, Grep and Glob meanwhile. The remote branch also receives the user's own commits (they swapped `.claude/skills` directories): `git pull --no-rebase` before pushing.
